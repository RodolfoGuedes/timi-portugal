# TIMI Portugal

Landing page estática, mobile-first, para apresentar a proposta TIMI em Portugal.

## Estrutura

- `index.html` — conteúdo da página
- `styles.css` — design responsivo
- `config.js` — links editáveis do afiliado e Telegram
- `script.js` — aplica a configuração aos botões

## Configuração

Em `config.js`, substitua `affiliateUrl` e `telegramUrl` pelos links reais quando estiverem definidos.

A página inicial não contém valores financeiros ou promessas de rendimento; esses elementos podem ser adicionados posteriormente com informação confirmada.
